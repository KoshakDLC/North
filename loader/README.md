# NorthLoader

Десктопный лоадер клиента: сам ставит Minecraft с Fabric и нужной Java, берёт свежую
сборку, кладёт её в `mods` и запускает игру. Официальный лаунчер не нужен —
одна кнопка «Запустить».
Написан на чистой Java (Swing с полностью ручной отрисовкой), внешних зависимостей нет —
нужен только JDK 17 или новее, тот же, которым собирается сам клиент.

![Главная](preview-home.png)

## Раздача людям

Один файл — `NorthLoader.exe`. При первом запуске достаёт UI в
`%LOCALAPPDATA%\Programs\NorthLoader\`. Если Java 17+ нет — предложит открыть
[Adoptium](https://adoptium.net/) (сам runtime больше не качает: тихая загрузка
exe ловит антивирусы).

```bat
cd loader
build-exe.bat    :: соберёт jar и упакует его внутрь NorthLoader.exe
```

Готовый `NorthLoader.exe` можно кидать людям. Чтобы убрать ложные срабатывания
VirusTotal почти полностью — подпиши exe Authenticode (сертификат Code Signing).

## Сборка и запуск (для разработки)

```bat
cd loader
build.bat        :: соберёт north-loader.jar
run.bat          :: соберёт, если нужно, и запустит
run.bat debug    :: то же, но с консолью — видно ошибки
NorthLoader.exe debug :: то же через exe
```

Для `run.bat` нужна **Java 17+**. Скрипты не полагаются на `PATH`: `find-java.bat`
перебирает `JAVA_HOME`, `%USERPROFILE%\.jdks`, Program Files и только в конце `PATH`.

> Не запускай `north-loader.jar` двойным кликом — Windows часто открывает его
> старой Java 8. Бери `NorthLoader.exe` или `run.bat`.

## Что делает при запуске

1. Находит папку игры (`%APPDATA%\.minecraft`) и создаёт в ней `mods`, если её нет.
2. Скачивает свежую сборку клиента и кладёт её в `mods`.
3. Ставит Minecraft 1.21.8, ресурсы, библиотеки, Fabric и Fabric API, если чего-то нет.
4. Берёт Java от Mojang (или подходящую из системы) и запускает игру напрямую.

Ключ лицензии вводится на вкладке «Запуск». Лоадер шлёт ключ и HWID на
сервер (`license.url`, по умолчанию `http://127.0.0.1:8787`), сохраняет
подписанный `%APPDATA%\WildClient\license.json` и только после этого
ставит игру / запускает клиент. Ник задаётся в настройках
(по умолчанию — имя пользователя Windows, обрезанное до допустимого offline-ника).

Для разработки без сервера: файл `%USERPROFILE%\.north-dev-unlock` и
`-Dnorth.license.dev=1`. Флаг `license.bypass` больше не открывает клиент.

Сессия (`sessionUntil`) roughly на сутки. Пока она жива — можно офлайн.
Потом лоадер/клиент обязаны достучаться до license-server; отозванный ключ
стирает `license.json`.

Сервер ключей — в каталоге [`../license-server`](../license-server).

## Откуда берётся сборка

По умолчанию — последняя опубликованная сборка (источник зашит в лоадере, в UI не показывается).

Скачанное лежит в `%APPDATA%\North\cache\`. Пока тег и размер файла совпадают,
повторной загрузки не будет — новая сборка скачается сама.

Источник можно переопределить, приоритет сверху вниз:

1. `client.jar` — путь к локальному джарнику, полностью отключает загрузку;
2. `client.url` — прямая ссылка на `.jar`;
3. встроенный канал обновлений;
4. если ничего не вышло — локальная сборка из `build/libs` (запасной вариант для разработки).

## Настройки

Хранятся в `%APPDATA%\North\loader.properties` и сохраняются сразу при изменении:

| Ключ | Смысл |
| --- | --- |
| `minecraft.dir` | папка игры; в интерфейсе не показана, пусто — `%APPDATA%\.minecraft` |
| `player.name` | ник в игре (offline); пусто — имя пользователя системы |
| `license.key` | последний введённый ключ активации |
| `license.url` | адрес API лицензий, по умолчанию `http://127.0.0.1:8787` |
| `client.url` | прямая ссылка на джарник вместо автообновления |
| `client.jar` | локальный джарник, отключает загрузку |
| `memory.gb` | выделяемая память |
| `launch.command` | своя команда запуска вместо встроенного старта |
| `auto.install` | обновлять клиент при запуске |
| `close.on.launch` | закрывать загрузчик после старта игры |

Java от Mojang лежит в `%APPDATA%\North\runtime\`, лог последнего запуска игры —
в `%APPDATA%\North\game.log`.

## Разработка

`tools/wild/loader/Preview.java` рендерит окно в PNG, чтобы смотреть на вёрстку без запуска:

```bat
javac -encoding UTF-8 -cp out -d out tools\wild\loader\Preview.java
java -cp out wild.loader.Preview preview.png 1
```

Второй аргумент — номер страницы (0 — «Запуск», 1 — «Настройки», 2 — «О клиенте»),
третий `busy` — состояние с прогрессом и заполненным журналом.

`tools/wild/loader/DownloadCheck.java` проверяет разбор релизов и саму загрузку.

`tools/wild/loader/MetaCheck.java` проверяет метаданные Mojang и Fabric без тяжёлых загрузок:

```bat
java -cp out wild.loader.MetaCheck
```

`tools/wild/loader/LaunchCheck.java` ставит игру в указанную папку и печатает командную
строку запуска, не открывая окно:

```bat
java -cp out wild.loader.LaunchCheck %TEMP%\wild-launch-check
```
